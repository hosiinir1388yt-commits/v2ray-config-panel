# سلطه جهانی — بازی استراتژی آفلاین

## اجرا
فایل `index.html` را با مرورگر باز کنید. نصب یا سرور لازم نیست.

## قابلیت‌ها
- منوی شروع، انتخاب کشور و ادامه بازی ذخیره‌شده
- نقشه شماتیک جهان با انتخاب کشور، زوم و حرکت
- اقتصاد نوبتی، خزانه، صنعت، انرژی، غذا و نفوذ
- بازار کالاها با قیمت‌های متغیر
- قراردادهای تجاری و درآمد هر نوبت
- دیپلماسی، بهبود روابط و کمک اقتصادی
- توسعه شاخص‌های نیروهای زمینی، هوایی و دریایی در سطح بازی‌وار
- پژوهش و درخت فناوری
- ساخت زیرساخت، بودجه ملی و رویدادهای تصادفی
- ذخیره خودکار در localStorage

## محدودیت نسخه
این نسخه یک بازی مرورگری آفلاین و نمونه اولیه است. نقشه جهان شماتیک است و کشورها/اقتصاد/نیروها برای گیم‌پلی ساده‌سازی شده‌اند؛ نقشه دقیق جغرافیایی، نبرد تاکتیکی، چندنفره آنلاین و هوش مصنوعی پیشرفته در این نسخه وجود ندارد.
