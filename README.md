# WORLD COMMAND — بازی استراتژی جهانی (نمونه قابل اجرا)

## اجرا
1. فایل ZIP را استخراج کنید.
2. `index.html` را در مرورگر باز کنید.
3. برای نقشه و تصاویر پس‌زمینه، اتصال اینترنت لازم است؛ نقشه از OpenStreetMap و Leaflet استفاده می‌کند.
4. بازی جدید را بزنید، کشور را انتخاب کنید و وارد نقشه شوید.

## امکانات نمونه
- رابط کاربری فارسی، منوی شروع و انتخاب کشور
- نقشه تعاملی جهانی با زوم و حرکت
- انتخاب واحدها و حرکت روی نقشه
- عملیات انتزاعی برای تغییر کنترل مناطق منتخب
- واحدهای زمینی، هوایی و دریایی
- ساخت کارخانه، بندر، فرودگاه، مرکز دفاع موشکی، مرکز پژوهش، کشتی‌سازی، رادار و شهرک
- مسیرهای تجاری هوایی، دریایی و زمینی با درآمد دوره‌ای
- دیپلماسی، شاخص روابط، فناوری و رویدادهای تصادفی
- هوش مصنوعی سبک برای تغییر روابط و رویدادهای بازار
- ذخیره و ادامه بازی با localStorage
- رابط واکنش‌گرا برای موبایل و دسکتاپ

## محدودیت‌ها
این یک نمونه اولیه مرورگری است، نه یک بازی استراتژی AAA. نقشه جغرافیایی از کاشی‌های عمومی آنلاین استفاده می‌کند؛ فهرست کشورها و شاخص‌ها در این نمونه نماینده همه کشورها نیست و نقاط کشورها برای تعامل بازی استفاده شده‌اند، نه مرزهای سیاسی دقیق. مدل جنگ و رهگیری کاملاً انتزاعی است و شبیه‌سازی دقیق تسلیحات یا تاکتیک‌های دنیای واقعی نیست. کنترل واحدها فعلاً حرکت نقطه‌ای روی نقشه است، نه ناوبری مسیرمحور یا فیزیک کامل. قابلیت‌های آنلاین چندنفره وجود ندارد.

## نکته درباره نقشه
استفاده از کاشی‌های OpenStreetMap باید مطابق سیاست استفاده و انتساب آن‌ها باشد. برای انتشار عمومی پرترافیک، یک ارائه‌دهنده کاشی مناسب یا سرور نقشه اختصاصی انتخاب کنید.
