# WORLD COMMAND — نسخه اصلاح‌شده و توسعه‌یافته

## فایل‌ها
- `index.html`، `style.css` و `app.js`: نسخه چندفایلی مناسب میزبانی استاتیک. هر سه را کنار هم آپلود کنید.
- `standalone.html`: نسخه تک‌فایلی برای سرویس‌هایی که فقط یک فایل HTML می‌پذیرند.

## اجرا
1. برای GitHub Pages، هر سه فایل اصلی را در یک پوشه قرار دهید و `index.html` را باز کنید؛ یا `standalone.html` را به `index.html` تغییر نام دهید.
2. اتصال اینترنت لازم است چون نقشه از Leaflet و کاشی‌های OpenStreetMap بارگیری می‌شود.
3. روی «شروع فرماندهی» بزنید، کشور را انتخاب کنید و «ورود به نقشه» را بزنید.
4. برای ذخیره و ادامه بازی از دکمه 💾 و گزینه «ادامه بازی ذخیره‌شده» استفاده کنید.

## امکانات
- رفع مسیر شروع بازی و نمایش مستقیم انتخاب کشور
- نقشه تعاملی جهانی و انتخاب کشور/منطقه
- حرکت انیمیشنی واحدهای زمینی، هوایی و دریایی
- ساخت‌وساز، فناوری، تجارت هوایی/دریایی/زمینی، روابط دیپلماتیک
- رخدادهای اقتصادی و هوش مصنوعی سبک
- هشدارهای دفاعی و رهگیری انتزاعی با احتمال موفقیت و پیام رویداد
- اختلال‌های تصادفی مسیرهای تجاری و هزینه‌های بازیابی
- ذخیره محلی و طراحی واکنش‌گرا

## محدودیت‌ها
این نمونه بازی استراتژی مرورگری است، نه بازی AAA. داده‌های کشورها در این نسخه محدود و نقاط کشورها تقریبی‌اند؛ مرزهای سیاسی دقیق همه کشورهای دنیا هنوز اضافه نشده‌اند. نبرد و دفاع، مدل بازی انتزاعی هستند؛ کنترل واقعی تسلیحات یا شبیه‌سازی عملیاتی دنیای واقعی وجود ندارد. بازی چندنفره و ذخیره ابری هم ندارد.

## عیب‌یابی
اگر نقشه خالی ماند، اینترنت و دسترسی به `unpkg.com` و `tile.openstreetmap.org` را بررسی کنید. اگر فقط یک فایل آپلود می‌کنید، از `standalone.html` استفاده کنید. برای GitHub Pages مطمئن شوید فایل‌ها در ریشه شاخه منتشرشده قرار دارند.


## نسخه ۳: زمان زنده و نقشه رنگی
- بازی دیگر وابسته به دکمه «روز بعد» نیست؛ زمان شبیه‌سازی خودکار جلو می‌رود.
- درآمد هر چند ثانیه اضافه می‌شود و روز بازی در پس‌زمینه پیش می‌رود.
- واحدها روی نقشه با حرکت نرم جابه‌جا می‌شوند و پس از مدت کوتاهی خودکار آماده می‌شوند.
- مرزهای کشورهای جهان از GeoJSON بارگذاری می‌شوند و هر کشور رنگ متمایز دارد؛ با موفقیت عملیات، کشور هدف به رنگ قلمرو بازیکن درمی‌آید.
- برای مرزهای دقیق به اینترنت نیاز است. اگر منبع GeoJSON در دسترس نباشد، نقشه پایه همچنان باز می‌شود.
