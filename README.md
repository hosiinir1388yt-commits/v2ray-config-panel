# V2Ray Config Panel — No Import Redesign

نسخه استاتیک و محلی پنل برای مدیریت اطلاعات کانفیگ، IP/Port و کاربران.

## حذف شده
Import URL / Import Config، ترافیک واقعی، سرعت، Ping واقعی، آنلاین بودن واقعی، Stop/Start واقعی، انقضای واقعی سرور و هر نوع کنترل مستقیم Xray/V2Ray.

## نکته
GitHub Pages فقط فایل استاتیک اجرا می‌کند. این پروژه خودش Xray/V2Ray اجرا یا کنترل نمی‌کند. IP:Port به‌تنهایی تضمین‌کننده وجود سرویس سازگار در مقصد نیست.

رمز پیش‌فرض: `admin123`
این رمز فقط محافظ رابط کاربری است و احراز هویت سروری واقعی محسوب نمی‌شود.
